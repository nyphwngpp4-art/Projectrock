# Before / After: The Thirty-Second Version

The argument for the redesign, defect by defect. Each row is something a
prospective patient can see on the current site today, next to how the demo
resolves it.

## What the current site is costing the practice

Every LASIK or cataract consult starts as a website visit. When the lead path
is broken or the site reads as neglected, those consults quietly go to
Fort Worth, Lubbock, or a competitor with a working "request appointment"
button. The redesign is not about prettier. It is about surgical consults that
currently leak out of a broken funnel.

## Defect by defect

| Current live site | This demo |
|---|---|
| Footer advertises **haircuts, facials, and waxing** on an ophthalmology practice's website (leftover Duda template content) | Footer carries contact info, verified hours, patient and provider resources, emergency guidance, and privacy links. Nothing else |
| Placeholder card titles like **"Faces of Humanity"** shipped to production | Every section is written for this practice, in patient language; unverifiable facts are visibly flagged instead of faked |
| **LASIK self-test link is broken**, the single strongest elective lead generator a practice website has | A working two-minute self-assessment that asks lifestyle questions only, collects zero PHI, and ends in a call/appointment path |
| **Three phone numbers with no labels**; patients guess which to dial | One primary number everywhere, click-to-call on mobile, secondary numbers documented for the practice's decision |
| "Since 1987" and "over 30 years" contradict each other on the same site | One founding claim, flagged for confirmation, used consistently |
| No clear path for **referring optometrists**, the practice's highest-value channel | A dedicated referring-provider pathway with urgent-referral instructions, one click from every page |
| Generic template design; nothing communicates an established surgical institution | Restrained medical design system: serif authority, high contrast, large type, mobile-first for the older patients and adult children who actually visit |
| Accessibility ignored, on a website whose audience has **impaired vision** | WCAG 2.2 AA throughout: contrast, focus states, keyboard navigation, reduced motion, screen-reader labels |
| Patient tools (portal, QuickClick bill pay) mixed indistinguishably with ordinary links | Secure external systems explicitly labeled and separated from information pages |
| No emergency guidance | Clear urgent-care guidance on medical pages, contact page, and footer |

## What the demo deliberately does not do

- It does not collect a single piece of patient information.
- It does not fabricate reviews, outcomes, credentials, or facility claims.
- It does not pretend integrations exist: portal, bill pay, and scheduling are
  honestly labeled placeholders that connect to the practice's approved secure
  systems during implementation.

That restraint is part of the pitch: it shows the practice what working with a
vendor that takes medical-website compliance seriously looks like.

## The one-line close

"Your current site tells patients no one is minding the store. This one tells
them an established surgical practice is. Which one should a cataract patient's
daughter find when she searches tonight?"
